Conectar sua equipe

Use o mesmo projeto Supabase nos dispositivos de todas as pessoas.

Use somente a chave pública. Nunca use service_role ou uma chave secret.

Configuração inicial no Supabase
  1. Execute este script SQL no SQL Editor.
  2. Em Authentication → Users, crie os usuários da equipe com e-mail e senha.
  3. No SQL Editor, autorize seus e-mails com o comando indicado abaixo.
  4. Cada pessoa conecta este app ao mesmo projeto e entra com sua própria conta.
insert into public.checklist_members (user_id)
select id from auth.users
where email in ('pessoa1@email.com',
'pessoa2@email.com', 'pessoa3@email.com')
on conflict do nothing;

Troque os exemplos pelos e-mails reais. Você pode autorizar mais pessoas pelo mesmo comando.
